# Programme-guide identity audit — 12 November 2026

This audit covers **all 11,042 sanitized target playlist rows** from the current published project and the project's **69 configured public EPG source indexes**. A complete inventory of source availability is published with every successful release as `EPG_Source_Status.json`; the per-channel source-candidate and risk report is `EPG_Public_Review.csv`.

It is **not** a promise that every live IPTV stream has been viewed or that every possible online guide has been inspected. A playlist name cannot prove which regional/time-shift feed the provider is actually transmitting.

## Confirmed findings and risk screening

- **239** playlist EPG identifiers are reused across display names whose normalized channel identity differs. This affects **830** rows. Many are harmless SD/HD aliases, but some include truly distinct regional or branded feeds, so these are flagged for review instead of assumed equivalent.
- **37** `NFL Teams` entries have no playlist EPG ID and should not automatically inherit local FOX/CBS station schedules even when a callsign appears in their name.
- **267** event/PPV-labelled channels may not have fixed, independently published schedules.
- **25** regional variants need exact regional listings rather than a generic national EPG channel.
- **10** entries contain a clearly inconsistent branded channel/EPG ID according to current static checks.
- **1** TV Land entry (`USA: TV LAND HD`) has no east/west identifying information or provider EPG ID.

These categories overlap; the raw counts must not be summed.

## TV Land: no arbitrary Eastern/Pacific choice

The old name-based match assigned generic `USA: TV LAND HD` to `TV.Land.HD.us2` without demonstrating that the subscribed stream is the Eastern feed. The current builder now **refuses to auto-match that generic name** and adds explicit, separately labelled TV Land Eastern/Pacific options only when each source actually provides a channel ID and current programmes.

In TiviMate, review any prior per-channel *Assign EPG* override; it may persist even after an XMLTV update. Then compare the programme currently airing in the real IPTV stream against the Eastern and Pacific guide options. If none matches, leave the station unassigned and contact the IPTV provider. **Do not fabricate a listing or choose a coast from the name alone.**

Independent TV Land schedule references:
- https://www.tvland.com/tv-schedule
- https://www.tvinsider.com/network/tv-land/schedule/
- https://www.epg.pw/last/465362.html?lang=en

**Guide update safeguards:** unit tests must pass; invalid times, expired records, duplicates and overlapping contradictory programme records are quarantined; only then can GitHub Actions replace the Release asset. Coverage means programmes are present in the *validated* XMLTV, not that the underlying live stream has been independently confirmed.

For a persistent mismatch, compare the displayed guide with the **current programme title visible on the actual IPTV stream**, verify the station callsign and east/west variant, then explicitly assign the correct guide in TiviMate.
